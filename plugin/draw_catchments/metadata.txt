name=Draw Catchments
description=A QGIS tool for drawing preliminary groundwater catchment areas from groundwater contours.
about=Draw Catchments creates preliminary groundwater catchment polygons around wells, monitoring stations and selected map locations using groundwater contour lines.
    
    It combines automatic hydraulic-gradient tracing with manual contour-based boundary drawing. Adjustable starting widths, an optional rounded closure around the well and editable polygons support hydrogeological interpretation directly on the QGIS map.
    
    The plugin preserves boundary paths and original calculations for comparison and supports export to GeoPackage, Shapefile and GeoJSON.
    
    Results are geometric proposals for hydrogeological review. The tool does not model pumping, recharge or capture width.
    
    Requires NumPy and SciPy in the QGIS Python environment.
